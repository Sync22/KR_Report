# 분류 라벨

스킬이 분류 역할을 지정하면 아래 표의 GitHub 라벨을 사용한다.

| 역할 | GitHub 라벨 | 의미 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 유지보수자 검토 필요 |
| `needs-info` | `needs-info` | 보고자의 추가 정보 필요 |
| `ready-for-agent` | `ready-for-agent` | 구현 조건이 정리되어 에이전트가 진행 가능 |
| `ready-for-human` | `ready-for-human` | 사람이 구현해야 함 |
| `wontfix` | `wontfix` | 진행하지 않기로 결정함 |
