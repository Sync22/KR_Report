# KRX Detail Documents

This folder contains detailed KRX/Data Marketplace source studies, field notes, sample capture runbooks, and schema-stage documents.

Use `docs/codex/krx-market-data-runbook.md` as the current canonical operating guide first. Use this folder only when deeper source evidence or historical capture detail is needed.

Boundaries:

- Automated KRX Data Marketplace collection stays limited to report-mentioned stocks, stock-level `[12009]`, and the approved 31-day window.
- Broad ingest, all-stock collection, and automated `[12008]` or `[12010]` collection remain out of scope unless separately approved.
- Do not include KRX keys, passwords, cookies, or other secret material.
